# HWMonitor MQTT Sender

The source and installation instructions are maintained in the [main repository](https://github.com/KarlSideProjects/hwmonitor-mqtt). The former separate releases repository has been removed.

The [installation guide](../docs/deployment/installation.md) provides one-line installers for Windows, Linux and Proxmox VE. The installers prompt for MQTT settings on first installation and retain recognized existing settings.
